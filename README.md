# Статистика — статичный прототип

Пиксельно выверенная HTML/CSS-версия мобильного экрана из Figma. Экран пока намеренно статичен: кнопки и элементы навигации не выполняют действий.

## Просмотр

Откройте `index.html` напрямую или запустите любой локальный статический сервер в корне проекта.

## Размер макета

- внешний кадр: 438 × 1664 px;
- экран приложения: 390 × 1616 px;
- шрифт: Manrope, подключён локально.
